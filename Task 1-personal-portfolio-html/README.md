## 💻 About The Project

This repository contains the **Personal Portfolio Webpage** for **Mariam Gamal**, a Computer Science Engineering student at Egypt-Japan University of Science and Technology (EJUST) and Software / AI Developer.

Developed as a project for the **Route IT Training Center** (Frontend Diploma C49), this project demonstrates clean application of **Pure Semantic HTML5 elements**, structured tabular layouts, social media integration, custom image assets, and multi-section interactive forms.

---

## ✨ Key Features

- 👤 **Profile Header**: Professional photograph paired with interactive SVG social media badges (LinkedIn, GitHub, Facebook, Instagram).
- 📑 **About Me & Skills Matrix**: Structured layout contrasting technical proficiencies (Python, Full-Stack Web, AI/RAG) with personal soft skills.
- 🌐 **Languages & Certification**: Language proficiency highlight featuring EF SET English C2 Certification.
- ⏳ **Experience & Education Timeline**: Structured timeline table detailing industrial internships (AMOC), engineering consultancy (SASEC), GenAI training (Tips Hindawi), and academic degree at EJUST.
- 🚀 **Projects Showcase**: Summary of featured projects including Python tools, Generative AI engines, Flask ordering app (Aura), LMS, and HMS.
- ✉️ **Interactive Contact Section**: Multi-section form styled with HTML `<fieldset>` and `<legend>` controls, including text inputs, date/time pickers, radio choices, interest checkboxes, source selection, and form submission.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic elements, tables, forms, input types, fieldsets, and legends.
- **Vector Graphics**: Custom SVG icons for social media handles.
- **Git & GitHub**: Version control system and online project hosting.

## 🚀 Getting Started

### Prerequisites
To view and test this project, all you need is a modern web browser:
- Google Chrome
- Mozilla Firefox
- Microsoft Edge
- Safari

### Local Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mariammgamall/personal-portfolio-html.git
   ```

2. **Navigate to the project folder:**
   ```bash
   cd personal-portfolio-html
   ```

3. **Open `index.html`:**
   - Double click `index.html` to open it in your default web browser, OR
   - If using VS Code, right click `index.html` and select **Open with Live Server**.
